Digital Detective 🔍

A Digital Investigation and Phishing Detection System

📌 About the Project

Digital Detective is a web-based digital investigation application developed using Java. It helps users examine suspicious emails, URLs, and text messages to identify potential phishing indicators.

The application provides an organized workspace for analysing suspicious content and maintaining investigation records.

🎯 Objectives

- Identify potential phishing indicators.
- Analyse suspicious emails, URLs, and messages.
- Provide risk assessment results.
- Organize investigation cases.
- Maintain evidence and analysis records.
- Provide a user-friendly investigation dashboard.

✨ Key Features

- User Registration and Login
- Investigation Dashboard
- Email Analysis
- URL Analysis
- Message Analysis
- Case Management
- Evidence Vault
- Risk Assessment
- Report Management

⚙️ How to Run

Prerequisites

- Java JDK 21 or compatible version
- Maven
- Visual Studio Code or another Java IDE

Steps

1. Clone or download this repository.
2. Open the project folder containing "pom.xml".
3. Open a terminal in that folder.
4. Run:

mvn spring-boot:run

5. Open your browser and visit:

http://localhost:8080

🔍 How It Works

1. The user logs into the application.
2. The user selects email, URL, or message analysis.
3. The submitted content is processed by the Java backend.
4. Rule-based checks identify predefined suspicious indicators.
5. A risk assessment is generated.
6. Scan information can be stored in the SQLite database.

⚠️ Disclaimer

Digital Detective is an educational project. Its rule-based analysis identifies potential warning signs and does not guarantee that an email, URL, or message is safe or malicious.
